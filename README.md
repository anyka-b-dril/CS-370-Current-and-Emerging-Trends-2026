# CS-370-Current-and-Emerging-Trends-2026
In this course, students explore advanced topics in CS, specifically Artificial Intelligence (AI) and machine learning. Students will analyze the role of ethics in current trends within the field as well as apply fundamental concepts of the field to solve complex problems in new ways.

<ul>
  <li><b>Briefly explain the work that you did on this project: What code were you given? What code did you create yourself?</b></li>
  <br>
  <p>In the Pirate Intelligent Agent project, I received much of the supporting content (Maze generation, environment logic, helper classes, environment state routines), maze object generation, and helper functions. I created the Q-Training algorithm that trained the agent to find the best possible navigation sequence to reach the treasure cell while maximizing the reward. With each turn, the agent either chooses a random valid exploration action or predicts the best exploitable action and moves down, up, right, or left. Each action yields a reward, providing the pirate with a measurable measure of success or failure. For instance, moving into a free space earns 1 point, a blocked space is penalized by 1 point, and a revisited space is penalized by 0.25 points. At the end of each game, the agent tallies its reward (score) and logs whether it won or lost. The pirate will also store each game in its experience replay. This experience replay stores past actions, the rewards received, and the resulting next states, which the network then uses to train the pathfinding algorithm. This technique imitates how humans create a mental map to navigate new locations.</p>

    <p>Computer scientists in machine learning develop, build, and advance algorithms using statistics and linear algebra to find hidden patterns in raw data, train models, supervise and test intelligent models, and build AI supporting infrastructure. Computer scientists figure out how to make computing systems faster, safer, and more energy-efficient to handle heavy AI workloads.     <li><b>How do I approach a problem as a computer scientist?</b></li>
    <br>
    <p>As a computer scientist, I approach most problems by deconstructing them. Many problems are unexpectedly complex and require thoughtful consideration to address each element for a complete solution. A problem can be broken down into smaller, more manageable sub-problems to filter out unnecessary details and create a solution that addresses all elements. The Intelligent Agent pathfinding problem can be broken down into defining the state space, initial state, goal state, valid actions, rewards, and search strategy. Next, I will look for similarities between this problem and things I have solved before. After that, I can begin designing a solution, whether that's an algorithm or a helper function. In this stage, I define the expected inputs and outputs, outline the solution steps with pseudocode or flow charts, and note possible edge cases. Finally, I can begin implementing and testing a solution.</p>
